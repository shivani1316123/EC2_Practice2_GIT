🔐 EC2 Bastion Host (Jump Server) Project

Securely connecting private EC2 instances using SSH

📌 Project Overview

This project demonstrates how to securely connect to a private EC2 instance using a Bastion Host (Jump Server). The private server is not exposed to the internet, improving security in cloud environments.

🧱 Architecture Diagram

Internet
  ↓
[ Bastion Host (Public EC2) ]
  ↓ SSH
[ Private EC2 (No Public IP) ]

⚙️ Steps Performed

  • Launched two EC2 instances (Public & Private)
  • Configured Security Groups
  • Connected to Bastion Host via SSH
  • Accessed Private EC2 through Bastion Host

🔐 Security Benefits

  • No direct public access to private server
  • Controlled SSH access
  • Improved infrastructure security
